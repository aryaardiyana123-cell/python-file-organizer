# Python File Organizer

## Description
This Python script automatically organizes files into folders based on file type.

## Features
- Organizes images (.jpg, .png)
- Organizes documents (.pdf, .docx)
- Organizes videos (.mp4)

## Technologies Used
- Python
- os
- shutil

## How to Run
1. Put files into sample_files folder
2. Run: python main.py
3. Files will be organized automatically
